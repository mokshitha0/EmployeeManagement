# Employee Management SQL

## 📌 Project Overview

This project is an Employee Management System implemented using MySQL.

It contains SQL queries to analyze employee information based on departments, salaries, cities, and joining dates.

The project demonstrates commonly used SQL concepts such as aggregate functions, grouping, filtering, sorting, and limiting results.

## 🗂️ Employee Table

The `Employee` table contains the following columns:

- `emp_id` – Employee ID
- `emp_name` – Employee Name
- `department` – Employee Department
- `salary` – Employee Salary
- `city` – Employee City
- `joining_date` – Employee Joining Date

## 📝 SQL Concepts Covered

- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- LIMIT
- COUNT()
- SUM()
- AVG()
- MAX()
- MIN()

## 🔍 Queries Included

The project includes SQL queries for:

1. Total employees in each department
2. Average salary in each department
3. Departments having more than one employee
4. Highest salary in each department
5. Lowest salary in each department
6. Departments with average salary greater than 50,000
7. Total salary expenditure for each department
8. Employees sorted by salary
9. Employees sorted by department and salary
10. Cities having more than one employee
11. Total salary paid in each city
12. Departments ordered by total salary expenditure
13. Number of employees earning more than 50,000 in each department
14. Difference between highest and lowest salary in each department
15. Top 3 highest-paid employees
